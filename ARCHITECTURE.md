# Folder Structure Guidelines

- `src/app/` : Pages & API Routes (Next.js App Router)
- `src/components/ui/` : Reusable UI Components (Buttons, Modals, Cards)
- `src/components/features/` : Feature-specific Components (PortfolioTable, StockChart)
- `src/lib/supabase/` : Supabase Client & Server Configurations
- `src/types/` : TypeScript Interfaces / Database Types
